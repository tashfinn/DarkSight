🌲 DOM & CSS Extractor
content.js Engine
STEP 1.1 • FILTERING
Leaf Node Extraction
Isolates leaf text nodes (children.length === 0). Ignores scripts, styles, extension UI (.dp-explain).
extractNodes()
STEP 1.2 • CLEANING
Text Normalization
Regex timer masking (\d:\d:\d ➔ TIMER), exact blacklist stripping, and decision keyword preservation.
normalizeText()
STEP 1.3 • STYLING
CSS & Contrast Math
Extracts computed styles, bounding box dimensions, upward background inheritance, and WCAG luminance.
window.getComputedStyle()
📸 Viewport Capture Engine
background.js Service Worker
STEP 2.1 • CAPTURE
Chrome Tab Interception
Calls native Chrome extension API to capture the exact rendered visible pixels without DOM cloning overhead.
captureVisibleTab()
STEP 2.2 • ENCODING
Base64 Frame Packaging
Strips data URI headers, extracts uncompressed binary base64 string, and bundles with tab dimensions.
dataUrl.split(',')[1]
STEP 2.3 • TIMEOUT & SAFETY
AbortController Guard
120-second timeout guard prevents memory leaks and network hangs during local Ollama model payload handoff.
new AbortController()
