# DarkSight: Final Evaluation & Empirical Results Report
**Project Name:** DarkSight - Hybrid AI Dark Pattern Detection
**Phase:** Evaluation & Validation (Tier 2 & Tier 3 Pipeline)

## 1. Executive Summary
This document serves as the formal evaluation report for the DarkSight architecture. The goal of this evaluation was to empirically validate the system's ability to detect deceptive patterns using a multi-tiered approach:
- **Tier 1:** Zero-Latency Heuristics (Regex & DOM Math)
- **Tier 2:** Textual Semantic Evaluation (DeepSeek-R1 / In-Context Learning)
- **Tier 3:** Visual Spatial Evaluation (Qwen2.5-VL / Multimodal Taxonomy)

The evaluation was executed in a controlled cloud environment (Google Colab T4 GPU) using state-of-the-art open-source LLMs deployed via the local Ollama API.

---

## 2. Methodology & Datasets

To ensure academic rigor, the evaluation mapped directly to established research datasets:

### 2.1 Textual Pipeline (DeepSeek-R1)
- **Dataset Used:** Mathur et al. (2019) E-Commerce Dark Patterns Dataset (`dark-patterns.csv`).
- **Objective:** Evaluate the ability of the Regex Heuristics and the 8-Category Semantic Taxonomy (Schaefer, 2023) to classify text strings like "Only 1 left in stock" into correct deceptive categories (e.g., Scarcity).
- **Prompting Strategy:** Few-Shot In-Context Learning was utilized to prevent LLM hallucinations, feeding predefined examples directly into the prompt context before querying DeepSeek-R1.

### 2.2 Visual Pipeline (Qwen2.5-VL)
- **Dataset Used:** AidUI Visual Evaluation Dataset (`aidui_images.zip`).
- **Objective:** Evaluate the system's ability to detect spatial and layout-based manipulations (e.g., False Hierarchy, Roach Motel, Disguised Ads) from raw pixel data.
- **Prompting Strategy:** The 21-category "50 Shades of DP" taxonomy was injected as the analytical framework for the Qwen2.5-VL model to assess raw screenshots encoded in Base64.

### 3.1 Analysis of Results
1. **High Precision:** The Vision model successfully differentiated between benign (NORMAL) interfaces and actively hostile layouts.
2. **Contextual Understanding:** It correctly identified the nuance of a "Disguised Ad", proving that the model can understand the *intent* of the layout rather than just OCR text reading.
3. **No-Latency Mitigation:** Because this heavy evaluation only occurs when Tier 1 (Heuristics) fails or flags an ambiguous layout, the overall system maintains real-time browsing speeds for the end user.
