What are Dark Patterns?

  • Deceptive UI and UX design tactics intentionally created to trick users.
  • Exploits human psychology and cognitive biases.
  • Manipulates user decision-making for business or financial gain.

DarkSight Approach

1️⃣ Detection

Finding the trap. Scans the page’s DOM, CSS and visual cues to locate manipulative elements before the user interacts.

  • DOM heuristics (hidden fields, misleading labels)
  • ML text analysis (biased phrasing, hidden fees)
  • Visual LLM detection (countdown timers, stock scarcity)

2️⃣ Countermeasure

Disarming the trap. Modifies or masks the deceptive element, preserving the user’s intended action.

  • Hide or remove the UI element
  • Replace with a neutral alternative
  • Show a warning tooltip explaining the manipulation

Phase 1: Detection Architecture

How DarkSight analyzes and identifies manipulative web elements in real-time:

1. DOM Heuristics

Fast, immediate scanning of HTML structure and CSS classes. Catches obvious known patterns using regex and structural rules.

2. NLP Text Pipeline

Local LLM (Mistral) analyzes the semantic intent of the text to understand context, bypassing simple keyword evasion.

3. Vision Fallback

Multimodal LLM (LLaVA) processes page screenshots to catch structural visual deceptions that text-analysis is blind to.

Paper Focus: Schaefer (2023)

Investigating Visual Countermeasures Against Dark Patterns

Implementation Scope: From this research, we adapted and implemented the Visual intervention strategies for our extension's user interface. Specifically, we integrated their most successful countermeasure: Highlight with Explanation (HL+E).

  • The Core Problem: Automatically detecting a pattern is useless if the user isn't effectively warned. However, silently hiding content can be dangerous, and unexplained warnings cause confusion.
  • Our Application: We use the HL+E concept as the immediate visual output whenever our system detects a manipulation attempt.
  • The Result: Users are alerted via a visual boundary and educated via an explanatory tooltip, allowing them to make an informed, unbiased decision.

Paper Focus: In-Context Learning

Automated Detection of Dark Patterns Using In-Context Learning

Implementation Scope: From this research, we implemented the Text (LLM) component of our detection pipeline. We adopted their Few-Shot Prompting methodology.

  • The Core Problem: Zero-shot classification with local LLMs often leads to hallucinations or misclassification of ambiguous text.
  • Our Application: We built a prompt structure containing strict academic definitions and carefully curated positive/negative examples (e.g., distinguishing a true "Flash Sale" from a normal date).
  • The Result: Strict model adherence, elimination of false positives, and highly accurate intent recognition by the Mistral AI.

Paper Focus: AidUI

Toward Automated Recognition of Dark Patterns in User Interfaces

Implementation Scope: From this research, we implemented the DOM & Visual Structure component. We adopted their mathematical logic for Structural Visual Analysis.

  • The Core Problem: Dark patterns are not always textual; "False Hierarchies" manipulate users by making decline options virtually invisible compared to massive accept buttons.
  • Our Application: Converted AidUI methodology into dynamic DOM calculations, comparing relative button sizes and color contrasts (using WCAG thresholds).
  • The Result: Objective, mathematical detection of "Attention Distraction" without relying on subjective AI interpretation.

Paper Focus: 50 Shades of Deceptive Patterns

Comprehensive Multimodal Vision Taxonomy

Implementation Scope: From this research, we implemented the Visual (Multimodal) component. We adopted their 21-category visual taxonomy for complex spatial deceptions.

  • The Core Problem: Many dark patterns (like Roach Motel, Hidden Costs, or Disguised Ads) rely on full-page layout tricks that text-only analysis is completely blind to.
  • Our Application: We use the LLaVA vision model to evaluate full viewport screenshots against this paper's comprehensive 21-category spatial taxonomy.
  • The Result: The ability to detect context-heavy, screen-wide manipulations that transcend text and code.

Paper Focus: Dark Pattern Sentinel

A Hybrid DOM Heuristics and LLM-Based Detection System

Implementation Scope: From this research, we implemented the System Architecture component. We adopted their overarching multi-tiered orchestration logic.

  • The Core Problem: Sole reliance on AI models is far too slow for web browsing, while sole reliance on DOM heuristics is brittle and easily bypassed by developers.
  • Our Application: We designed our extension around this exact Hybrid Framework, combining lightweight frontend scripts with powerful backend AI.
  • The Result: A highly scalable, real-time tool that balances latency with deep analytical accuracy, never compromising browsing speed.
